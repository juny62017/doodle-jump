# Doodle Jump Game

A simple browser based Doodle Jump game made with html css and javascript

The player automatically jumps from platform to platform. 
Your goal is to keep moving upward without falling off the screen. 
Some platforms move..... while others break after you land on them.

## Controls

### Desktop

* Left Arrow or A ----- Move left
* Right Arrow or D ----— Move right

### Mobile

Use the left and right arrow buttons shown at the bottom of the game.


## How the Game Works

The character automatically jumps when it is landing on a platform.  
When the player is higher , the camera follows and generates new platforms above the screen
Platforms that move below the visible area are discarded.  
The higher the player goes the higher the score. 
The game ends when the player falls off the screen.
